# Banana Coconut Privacy Policy

Banana Coconut does not collect, store, or sell personal data.

Photos selected by users are processed locally on-device to generate gameplay experiences and memory questions.

Voice input and speech recognition are used only for gameplay interaction and are not stored or transmitted to external servers.

No account creation is required.

No third-party advertising or tracking SDKs are currently used.

If future updates introduce online features or cloud syncing, this privacy policy may be updated accordingly.
